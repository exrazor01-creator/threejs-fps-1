Tidebreak: a round-based tactical FPS in a night saltworks on the coast. You defend Saltworks No. 9 alone against four Drifters who push the Evap Pans or the Pump House, plant a charge, and guard it — stop the plant, or defuse the charge before it blows. Five weapons, Squall HE and Fog smoke grenades, kevlar and a defuse kit, a buy phase between rounds, and bots that walk routes, hold angles, react to gunfire and rotate to the planted site. First to five rounds takes the yard.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
